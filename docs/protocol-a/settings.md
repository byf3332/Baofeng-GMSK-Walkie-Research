# 设置

## 信道 Flags

信道 Flags 位于信道记录偏移 `0x0C`。

| Bit | 掩码 | `0` | `1` |
| --- | --- | --- | --- |
| 7 | `0x80` | 跳频关闭 | 跳频开启 |
| 4 | `0x10` | 加入扫描 | 排除扫描 |
| 3 | `0x08` | 低功率 | 高功率 |
| 2 | `0x04` | FM | NFM |
| 1 | `0x02` | 模拟对讲 | 加密对讲 |
| 0 | `0x01` | 繁忙锁定开启 | 繁忙锁定关闭 |

信道记录偏移 `0x0D` 的 bits 0–4 为加密密钥 `0–31`，bits 5–7 保留。

## 通用配置 `0x02B0`

| 绝对地址 | 偏移 | 字段 | 编码 |
| --- | --- | --- | --- |
| `0x02B0` | 0 | 语音提示 | `00` 关闭，`01` 开启 |
| `0x02B1` | 1 | 提示语言 | `00` 英文，`01` 中文 |
| `0x02B3` | 3 | VOX | `00` 关闭，`01` 开启 |
| `0x02B4` | 4 | VOX 增益 | `01–05` |
| `0x02B6` | 6 | 低压禁止发射 | `00` 关闭，`01` 开启 |
| `0x02B7` | 7 | 高压禁止发射 | `00` 关闭，`01` 开启 |
| `0x02B8` | 8 | 报警 | `00` 关闭，`01` 开启 |
| `0x02B9` | 9 | 降噪 | `00` 关闭，`01` 开启 |

## 系统配置 `0x03C0`

| 绝对地址 | 偏移 | 字段 | 编码 |
| --- | --- | --- | --- |
| `0x03C0` | 0 bit 0 | 按键提示音 | `0` 关闭，`1` 开启 |
| `0x03C0` | 0 bit 1 | 省电 | `0` 关闭，`1` 开启 |
| `0x03C1` | 1 | 静噪 | `00` 常开，`01` 常规，`05` 加强，`09` 严格 |
| `0x03C2` | 2 | 侧键 | `00` 关闭，`01` 监听，`02` 高低功率，`03` 报警 |
| `0x03C3` | 3 | 发射超时 | `00` 关闭，`01–0A` 对应 30–300 秒 |
