# 实时语音

## 模式控制

| 操作 | payload |
|---|---|
| 开启无网会话 | `00 02 04 07 01` |
| 关闭无网会话 | `00 02 04 07 00` |
| 按下 PTT | `00 02 04 02 01` |
| 松开 PTT | `00 02 04 02 00` |
| PTT 状态确认 | `00 82 04 02` |

## 语音编码

| 参数 | 值 |
|---|---|
| Codec | AMR-NB MR475 |
| 采样率 | 8000 Hz |
| PCM | mono PCM16LE |
| PCM 帧 | 320 字节 |
| 帧时长 | 20 ms |
| 编码帧 | 12 字节 |

AMR-NB MR475 的 IETF 存储帧由 1 字节 ToC 和 12 字节 payload 构成。AT2 仅传输 12 字节 payload。解码为 IETF 存储帧时在前面添加 `04`。

## 发送帧

实时语音使用 family `02`、command `04`、subcommand `03`。

| 类型 | payload | 时长 |
|---|---|---:|
| 常规包 | `00 02 04 03 00 00 [60-byte voice]` | 100 ms |
| 尾包 | `00 02 04 03 00 00 [48-byte voice]` | 80 ms |

常规包连接 5 个编码帧，发送间隔约 100 ms。尾包连接 4 个编码帧。

## 接收帧

设备发送 family `02`、command `04`、subcommand `03`。去除 subcommand 后的前导零，剩余数据按 12 字节切分为 AMR-NB MR475 编码帧。
